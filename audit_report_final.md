`{page}_{section}_{purpose}_{number}_{variant}.{extension}`

## TOP 10 MOST IMPORTANT FINDINGS

1. **Spaces in folder names**: Folders like `Index Hero` and `iconic 14` contain spaces. This causes `%20` in URLs and is a deployment risk.

2. **Case Sensitivity**: Some files and folders have mixed case (e.g., `Home`, `Desktop`), which can break on Linux-based hosting environments like Vercel or Netlify.

3. **Missing Mobile/Desktop Variants**: Some files lack a clear pair counterpart in their naming convention.

4. **Unclear Filenames**: Files like `person.jpg` or `dscf0463-copy.webp` lack context.

5. **Broken References**: Several image paths referenced in code do not match physical files exactly due to case or spacing.

6. **Inconsistent Pathing**: Mixed use of `/images/` and `/media/images/`.

7. **Missing Context**: Many files are in `public/media/images/misc/` and lack page context in their names.

8. **Extension Mismatches**: Referencing `.jpg` when `.webp` exists, or vice versa (needs manual verification from broken refs list).

9. **Duplicate Filenames**: Some files might be duplicates if placed in different folders but identically named.

10. **Centralized Manifest Missing Some Assets**: Not all images are in `asset-manifest.ts`, making them harder to track.
